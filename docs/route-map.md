# Hockey Ops Player Directory — Route Map

Source of truth: `docs/requirements-brief.md`  
Scaffold context: `docs/scaffold-notes.md`  
Framework: TanStack Start + TanStack Router (file-based routes under `src/routes/`)

## Why this map exists
Staff on arena wifi must open bookmarkable URLs and see a consistent shell.
This document locks path names and file homes before page UI is built.

## Route table

| URL path | Kind | Purpose (hockey ops) | Route file (planned) | Bookmarkable? |
|----------|------|----------------------|----------------------|---------------|
| `/` | static | Home / directory landing | `src/routes/index.tsx` | yes |
| `/players` | static | Full players list | `src/routes/players/index.tsx` | yes |
| `/players/$playerId` | dynamic | One player's detail page — bookmarkable per player | `src/routes/players/$playerId.tsx` | yes (each id is its own URL) |
| `/games` | static | Games index / schedule views | `src/routes/games/index.tsx` | yes |

## Path segments (plain language)
- **Static segment**: a fixed word in the URL (`players`, `games`). Same for every staff member.
- **Dynamic segment**: `$playerId` is a placeholder that changes per player. Example: `/players/42` is a unique bookmarkable URL for player 42.
- **Index route**: the default page for a folder path (e.g. `/players` → `players/index.tsx`).

## Root layout
- File: `src/routes/__root.tsx`
- Role: shared shell for all pages. Renders `<Outlet />` so every child route appears inside the shared header.
- Contains: Hockey Ops Directory header, nav links to Home / Players / Games, and `<Outlet />` for child routes.
- Out of scope for root: player tables, filters, or fetch logic (later steps).

## Generated route tree
- File: `src/routeTree.gen.ts`
- Role: auto-generated by TanStack Router from files in `src/routes/`.
- Rule: regenerate via project script; do not hand-edit permanently.

## Layout + child relationship

\```text
__root (shell: header + outlet)
├── index                    → /
├── players/index            → /players
├── players/$playerId        → /players/:playerId
└── games/index              → /games
\```

## src/routes/__root.tsx summary
The root layout is implemented at `src/routes/__root.tsx` using `createRootRoute`.
It renders a shared HTML shell with:
- A `<header>` containing "Hockey Ops Directory" branding and nav links
- A `<main>` element containing `<Outlet />` where child routes render
- No player data, no games tables, no fetch logic

## src/routeTree.gen.ts summary
Generated by TanStack Router. Wires `__root` and all route files under `src/routes/`
into the router. Regenerated automatically when `npm run dev` is run.
